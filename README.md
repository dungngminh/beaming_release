# Beaming releases

Downloads and issue tracker for **Beaming**, the macOS app that mirrors real Android phones, iPhones and iPads on the Mac, each in its own true-to-life device frame.

## Download

Get the latest DMG from **[Releases](https://github.com/dungngminh/beaming_release/releases/latest)**, open it and drag Beaming to Applications.

- Requires macOS 15 or later.
- Beaming checks this page for new versions. Settings › Updates checks on demand.

## Report a problem or ask for a feature

[Open an issue](https://github.com/dungngminh/beaming_release/issues/new). Please include your Beaming and macOS versions, and the device you were mirroring.

Please don't post your license key in an issue.

This repository holds releases only; Beaming's source code is private.
